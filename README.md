One line: a roast of the AI agent our own team built.

> My agent keeps a 166-megabyte diary of everything it ever did, reads it before every reply, and still forgets what it promised me yesterday.

## Run it

```sh
node main.ts
```

Writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).

## Files

- `main.ts` — writes the roast to `/output/entry.txt`, deterministic, no network.
- `LICENSE` — MIT.
